# Smart Parking System

## Project Overview

An IoT-based smart parking system with a capacity of three vehicles.

The system integrates ESP32 hardware, MQTT communication,
a backend service, parking-duration management and a mobile application.

| Farah | Flutter Mobile Application |

## Main Features

- Three-car parking capacity
- Entry and exit detection
- Automatic barrier control
- Available and full parking status
- MQTT communication
- Parking-duration tracking
- Estimated departure and remaining time
- Mobile application

## Project Structure

- hardware/: Hardware design and testing
- firmware/: ESP32 firmware
- backend/: Backend services and duration module
- mobile_app/: Flutter application
- docs/: Architecture and integration documentation
- tests/: Project tests
